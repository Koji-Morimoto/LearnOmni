# 用語と登場人物

## なぜ用語を先に固定するのか

Omniverse Kit の公式ドキュメントとソースコードは、3Dビューに表示される矢印や回転リングのことを "manipulator" と呼ぶ。日本語でこれを「マニピュレータ」と書くと、ロボットの腕を指す同じ語と衝突する。関節角度を扱うノートブックでこの2つを同じ語で書くと、どちらの話かが読み取れなくなる。

そこで、このノートブック全体で使う語を先に決めて固定する。以降のページでは、ここで定義した語だけを使い、途中で言い換えない。

## 語の定義

### 操作ハンドル

3Dビューに重ねて表示される、ドラッグして値を変える図形。並進モードで出る3本の矢印、回転モードで出る3本のリングがこれにあたる。

Kit のドキュメントとクラス名では "manipulator" と呼ばれる。**このノートブックでは常に「操作ハンドル」と書き、「マニピュレータ」とは書かない。**

### ロボットアーム

機械としての腕。関節角度を変える対象。**このノートブックでは常に「ロボットアーム」と書く。**

### 拡張機能

Kit の機能追加単位。1つのフォルダと、その中の `extension.toml` という設定ファイル1つで構成される。`omni.kit.widget.toolbar` のようなドット区切りの ID を持つ。

C# との対応で言えば、NuGet パッケージに「アプリ起動時に呼ばれる初期化フック」と「依存パッケージの宣言」が付いたものに近い。実行中に個別に有効化・無効化できる点が NuGet と違う。

Isaac Sim 6.0.1 で使う拡張機能は2系統に分かれる。

| ID の接頭辞 | 提供元 | 入手方法 |
|---|---|---|
| `isaacsim.` | Isaac Sim | Apache 2.0 で `isaac-sim/IsaacSim` リポジトリに公開されている [^1] |
| `omni.kit.` | Kit SDK | NVIDIA の配布物としてインストール先に同梱される。リポジトリ公開はされていない |

このノートブックで扱うツールバー関連は、すべて `omni.kit.` 側になる。ソースはリポジトリにないが、**Python ファイルは平文のままインストール先に入っている**ため読める。読み方は [[04_モードが排他になる仕組み]] で扱う。

### settings

アプリ全体で共有される、階層構造を持った設定値の保管場所。`/app/transform/operation` のようなスラッシュ区切りのパス文字列で1個の値を読み書きする。

C# との対応で言えば、`IConfiguration` のようなキー階層を持つ設定オブジェクトに、値変更の通知機能が付いたものになる。違いは、実行時に自由に書き換えられ、書き換えが即座に他のコードへ通知される点にある。

詳細は [[02_settingsは状態の置き場所]] で扱う。

### omni.ui

Kit の UI を構築するための Python ライブラリ。OS 標準のウィンドウ部品（Windows の Win32 コントロール等）は使わず、独自に描画する。

このノートブックで出てくる部品は2つある。

| 名前 | 種別 | 説明 |
|---|---|---|
| `omni.ui.Widget` | クラス | 画面に置ける部品全般の基底 |
| `omni.ui.ToolButton` | クラス | 押した状態を保持するボタン。押下状態を自分で持たず、外部の「モデル」オブジェクトに問い合わせる |

「モデル」は、値そのものを持つ小さなオブジェクトを指す `omni.ui` の用語になる。C# の `INotifyPropertyChanged` を実装したビューモデルに相当し、ボタンの見た目はモデルの値に追従する。

### ツールバー

画面上部（既定では左上）に並ぶアイコンの列。Kit ではこれが2つの拡張機能に分かれている。

| 拡張機能 | 役割 |
|---|---|
| `omni.kit.window.toolbar` | ドッキング可能な**ウィンドウ**を作る側 [^2] |
| `omni.kit.widget.toolbar` | ツールバーの**ウィジェット本体**。並進・回転・スケールなどの組み込みツールを同梱する [^3] |

ウィジェット本体は任意の UI フレームに置ける汎用部品で、通常の Kit アプリではウィンドウ側の中に組み込まれてメインツールバーになる。ウィジェット本体はアプリ内に1つしか存在しない [^3]。

### ビューポート

3Dシーンを描画するウィンドウ。Kit では同時に複数開ける。この「複数ありうる」という性質が [[06_操作ハンドルと描画レイヤ]] の設計理由になる。

### 描画レイヤ

ビューポートに重ねて描く層。操作ハンドルやハイライトはこの層に置かれる。Kit のドキュメントとコードでは "Scene" と呼ばれる。

USD の「ステージ」（保存対象の3Dデータ）とは別物になる。描画レイヤに描いたものはファイルに保存されず、Undo 履歴にも載らない。

### ステージと prim

USD（Universal Scene Description）が扱う3Dデータの本体をステージと呼び、その中に置かれる個々の要素を prim と呼ぶ。ロボットアームのリンクや関節も prim として表現される。

このノートブックでステージと prim が出てくるのは、[[06_操作ハンドルと描画レイヤ]] で「操作ハンドルは prim に依存しない」ことを示す場面と、[[09_関節角度モードの組み立て]] で角度の書き込み先を選ぶ場面に限られる。

## 語が実在することを確認する

上で挙げた拡張機能が手元の Isaac Sim に入っていることは、次のスクリプトで確認できる。

Isaac Sim の Script Editor（メニューの Window → Script Editor）に貼り付けて実行する全文になる。ファイルとして保存する必要はない。

```python
# ===== 目的：このノートブックで扱う拡張機能が読み込めることを確認する =====
import carb

MODULES = [
    "omni.kit.widget.toolbar",        # ツールバーのウィジェット本体
    "omni.kit.window.toolbar",        # ツールバーのウィンドウ
    "omni.kit.manipulator.transform", # 操作ハンドルの基本部品
    "omni.kit.manipulator.prim.core", # 操作ハンドルを USD prim に繋ぐ層
    "omni.kit.manipulator.selector",  # 複数の操作ハンドルの順位付け
    "omni.kit.hotkeys.core",          # ホットキーの登録簿
    "omni.ui",                        # UI ライブラリ
    "carb.settings",                  # 設定値の保管場所
]

import importlib

for name in MODULES:
    try:
        mod = importlib.import_module(name)
        carb.log_warn(f"OK   {name}  ->  {getattr(mod, '__file__', '(組み込み)')}")
    except Exception as exc:
        carb.log_warn(f"NG   {name}  ->  {type(exc).__name__}: {exc}")
```

実行すると、Console ウィンドウ（メニューの Window → Console）に1行ずつ出る。出力の形は次のようになる。

```text
OK   omni.kit.widget.toolbar  ->  C:\isaacsim\kit\exts\omni.kit.widget.toolbar\omni\kit\widget\toolbar\__init__.py
OK   omni.kit.window.toolbar  ->  C:\isaacsim\kit\exts\omni.kit.window.toolbar\omni\kit\window\toolbar\__init__.py
OK   omni.kit.manipulator.transform  ->  C:\isaacsim\kit\extscore\...\__init__.py
（以下同様）
```

パスの途中が `kit\exts` になるか `extscache` になるかは、その拡張機能が Kit 本体に同梱されているか、別途取得されたかで変わる。**どちらになるかは環境で決まるため、上のパスは形を示す例であり、値そのものは【未確認】**になる。実際の値はこのスクリプトの出力で確定する。

`NG` が出た拡張機能があれば、その機能は現在のアプリ構成で無効になっている。メニューの Window → Extensions で検索して有効化すれば読み込めるようになる。

## 理解度確認問題

1. 「操作ハンドル」と「ロボットアーム」は、Kit の公式ドキュメントではどちらも同じ英語の語で呼ばれる。その語は何か。
2. `omni.kit.widget.toolbar` のソースコードが GitHub で見つからないのはなぜか。読む方法はあるか。
3. 描画レイヤに描いたハイライトは、USD のファイルに保存されるか。

<details>
<summary>解答</summary>

1. manipulator。この衝突を避けるため、このノートブックでは日本語で別の語に固定している。
2. `omni.kit.` 系は Kit SDK の配布物で、リポジトリ公開の対象が `isaacsim.` 系に限られるため。ただし Python ファイルは平文でインストール先に入っているので読める。
3. 保存されない。描画レイヤはステージとは別物で、Undo 履歴にも載らない。

</details>
