# リファレンス

引くための表を集めたページになる。各項目には「何のためにあるか」の一言を付けてある。

## 拡張機能

| 拡張機能 | 何のためにあるか |
|---|---|
| `omni.kit.window.toolbar` | ツールバーをドッキング可能なウィンドウとして表示する [^1] |
| `omni.kit.widget.toolbar` | ツールバーのウィジェット本体。並進・回転・スケール等の組み込みツールを同梱する [^2] |
| `omni.kit.manipulator.transform` | 操作ハンドル（矢印・回転リング）の基本部品を提供する [^3] |
| `omni.kit.manipulator.prim` | 操作ハンドルを USD prim に接続する。core / usd / fabric の3つを束ねたもの [^4] |
| `omni.kit.manipulator.selector` | 複数種類の操作ハンドルに順位を付け、1つだけを選ばせる [^5] |
| `omni.kit.viewport.registry` | 描画レイヤのクラスを登録し、ビューポートごとに生成させる |
| `omni.kit.hotkeys.core` | キーとアクションの対応を一括管理する [^6] |
| `omni.kit.actions.core` | 処理の実体に ID を付けて登録する |
| `omni.ui` | UI 部品を組み立てる |
| `omni.ui.scene` | 3Dビューに重ねる図形を描く [^7] |

## settings のキー

| キー | 型 | 何のためにあるか | 出典 |
|---|---|---|---|
| `/app/transform/operation` | 文字列 | 現在のトランスフォーム操作を保持する | [^8] |
| `/persistent/app/transform/operation` | 文字列 | 同上の永続版 | [^8] |
| `/app/transform/moveMode` | 文字列 | 並進をローカル座標系で行うかグローバル座標系で行うか | [^8] |
| `/app/transform/rotateMode` | 文字列 | 回転をローカル座標系で行うかグローバル座標系で行うか | [^8] |
| `/app/viewport/snapEnabled` | 真偽値 | スナップの有効・無効 | [^9] |
| `/persistent/exts/omni.kit.manipulator.selector/orders/<名前>` | 整数 | 操作ハンドルの順位 | [^5] |
| `/persistent/exts/omni.kit.manipulator.prim.core/manipulator.placement` | 文字列 | 操作ハンドルを置く基準点の決め方 | [^10] |
| `/exts/omni.kit.manipulator.prim.core/tools.enabled` | 真偽値 | 操作ハンドルの道具立てを有効にするか | [^10] |

## API 一覧

### settings

| 呼び出し | 何のためにあるか |
|---|---|
| `carb.settings.get_settings()` | settings の入口オブジェクトを得る |
| `.get(path)` | 値を1個読む |
| `.set(path, value)` | 値を1個書く |
| `.subscribe_to_node_change_events(path, fn)` | 1個のパスの変更を購読する。戻り値は購読 ID [^11] |
| `.subscribe_to_tree_change_events(path, fn)` | パス以下すべての変更を購読する [^11] |
| `.unsubscribe_to_change_events(id)` | 上の2つで得た ID を解除する [^11] |

### ツールバー

| 呼び出し | 何のためにあるか |
|---|---|
| `omni.kit.widget.toolbar.get_instance()` | ツールバー本体を取得する |
| `Toolbar.add_widget(group, priority, context='')` | グループを登録する [^12] |
| `Toolbar.remove_widget(group)` | 登録を外す [^12] |
| `Toolbar.get_widget(name)` | ウィジェット名で部品を1個取り出す [^12] |
| `Toolbar.acquire_toolbar_context(context)` | 現在のコンテキストを切り替える。戻り値はトークン [^12] |
| `Toolbar.release_toolbar_context(token)` | 切り替えを戻す [^12] |
| `Toolbar.get_context()` | 現在のコンテキストを取得する [^12] |
| `WidgetGroup.create(default_size)` | 部品を作って返す [^13] |
| `WidgetGroup.get_style()` | 部品の見た目を辞書で返す [^13] |
| `WidgetGroup.clean()` | 後始末する [^13] |
| `WidgetGroup.on_added(context)` | 追加されたことを知る [^13] |
| `WidgetGroup.on_removed()` | 外されたことを知る [^13] |
| `WidgetGroup.on_toolbar_context_changed(context)` | コンテキストが変わったことを知る [^13] |

### 操作ハンドルと譲り合い

| 呼び出し | 何のためにあるか |
|---|---|
| `RegisterScene(クラス, "名前")` | 描画レイヤのクラスを登録する。戻り値を `None` にすると解除される [^14] |
| `ManipulatorBase.enabled` | この操作ハンドルが有効かを返す [^5] |
| `ManipulatorBase.on_selection_changed(stage, selection)` | 選択を扱えたかを返す。`selection` が `None` なら必ず `False` [^5] |
| `ManipulatorOrderManager.orders_dict` | 順位の辞書を取得する [^15] |

### ホットキー

| 呼び出し | 何のためにあるか |
|---|---|
| `omni.kit.hotkeys.core.get_hotkey_registry()` | ホットキーの登録簿を得る |
| `.register_hotkey(ext_id, key, action_ext_id, action_id, filter=...)` | キーとアクションを結び付ける [^16] |
| `.deregister_hotkey(...)` | 1個ずつ解除する [^16] |
| `.deregister_all_hotkeys_for_extension(ext_id)` | その拡張機能の分をまとめて解除する [^16] |
| `HotkeyFilter(windows=[...])` | 有効なウィンドウを限定する [^16] |
| `omni.kit.widget.toolbar.Hotkey` | ツールバーのボタンに対応する簡易なキー割り当て [^17] |

## 調査スクリプト集

### 拡張機能の実ファイル位置を出す

```python
import omni.kit.widget.toolbar as t
print(t.__file__)
```

### クラスの実装を読む

```python
import inspect
from omni.kit.widget.toolbar import Toolbar
print(inspect.getsource(Toolbar))
print(inspect.getsource(Toolbar.add_widget))
```

### settings の部分木をまとめて見る

```python
import carb.settings
print(carb.settings.get_settings().get("/app/transform"))
```

出力の形は辞書になる。

```text
{'operation': 'move', 'moveMode': 'Global', 'rotateMode': 'Global'}
```

### 開いているウィンドウ名を一覧する

```python
import omni.ui as ui
for w in ui.Workspace.get_windows():
    print(w.title)
```

### 拡張機能フォルダの絶対パスを得る

```python
import omni.kit.app
mgr = omni.kit.app.get_app().get_extension_manager()
ext_id = mgr.get_enabled_extension_id("omni.kit.widget.toolbar")
print(ext_id, mgr.get_extension_path(ext_id))
```

## 未確認事項の一覧

| # | 内容 | 確認方法 |
|---|---|---|
| 1 | 選択モードのとき `/app/transform/operation` に入る値 | [[02_settingsは状態の置き場所]] の変更追跡スクリプトを動かし、選択ボタンを押す |
| 2 | モードのキーを読み書きしている実装ファイルとクラス | [[04_モードが排他になる仕組み]] の全文検索スクリプトを動かす |
| 3 | コンテキスト切替時に既定コンテキストのボタンが残るか | [[05_ツールバーのコンテキスト]] の観測スクリプトを動かし、ツールバーを目視する |
| 4 | 操作ハンドルの順位は数値が小さいほど先か大きいほど先か | [[07_複数の操作ハンドルの譲り合い]] で自作の順位を変え、問い合わせ順を Console で見る |
| 5 | 矢印キーの押しっぱなしでホットキーが連続発火するか | [[08_ホットキー]] のスクリプトで押し続け、行が1回か連続かを見る |
| 6 | Kit 110 系の個別拡張機能ドキュメントの所在 | 手元の実装を読むほうが速いため、当面は不要 |

このノートブックの記述は、Kit 108 系までの公式ドキュメントで裏付けが取れた内容に基づいている。Isaac Sim 6.0.1 が使う Kit 110.1.2 の個別ドキュメントは今回参照できていない。API の構成が変わっていないことは、上のスクリプトで手元の実装を読めば確認できる。

## 理解度確認問題

1. 操作ハンドルの順位を保持している settings のパスはどれか。
2. その拡張機能が登録したホットキーをまとめて外す呼び出しは何か。
3. 描画レイヤの登録を解除する方法は何か。

<details>
<summary>解答</summary>

1. `/persistent/exts/omni.kit.manipulator.selector/orders/<名前>`。
2. `deregister_all_hotkeys_for_extension(拡張機能のID)`。
3. `RegisterScene(...)` の戻り値を保持していた変数を `None` にする。

</details>
