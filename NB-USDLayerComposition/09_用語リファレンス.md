# 09. 用語リファレンス

このノートブックで定義した用語を引くためのページ。各項目に「何のためにあるか」を必ず付ける。

## 1. 用語一覧

| 用語 | 一言定義 | 何のためにあるか | 定義ページ |
|---|---|---|---|
| 合成（composition） | 複数のレイヤーを重ねて1つのシーンを計算する処理 | シーンを「保存された状態」ではなく「計算結果」にするため | 01 |
| レイヤー（layer） | 重ねられる記述の1枚。実体は1つの USD ファイル | 記述を複数ファイルに分割し、並行作業と差し替えを可能にするため | 02 |
| ステージ（stage） | 合成の結果として得られるシーン全体。メモリ上にのみ存在する | いま見えているものを表すため。ファイルとして保存はできない | 01 |
| レイヤーメタデータ欄 | ファイル冒頭の `( ... )` の中。レイヤー全体に効く設定を置く | 個別プリムではなくレイヤー全体の情報を持つため | 02 |
| Spec ツリー | ファイル本体。プリムパスをキーにした意見の集まり | どのパスについて何を主張するかを記述するため | 02 |
| 意見（opinion） | 1枚のレイヤーが、あるパスについて持つ1件の記述 | 複数レイヤーの主張を独立に扱い、後から比較・勝敗判定するため | 02 |
| Spec | 意見を保持する記録の単位。PrimSpec と PropertySpec がある | レイヤー内の記述をパス単位で構造化するため | 02 |
| PrimSpec | プリムパスについての、1レイヤー分の意見 | ステージ上の Prim と区別するため | 02 |
| PropertySpec | プロパティ（属性・リレーション）についての、1レイヤー分の意見 | 属性値の意見をパス単位で持つため | 02 |
| Prim | ステージ上の要素。複数の PrimSpec を合成した結果 | シーンに置かれるもの（ロボット・カメラ・ライト）を表すため | 01 |
| プリムパス | `/World/Robot/link1` のような、Prim を一意に指す文字列 | 複数レイヤーが「同じもの」について意見を言うためのキー | 01 |
| `def` | プリムを定義する書き出し。ステージ上に実体を作る | アセット本体を記述するため | 02 |
| `over` | 定義せず、属性についての意見だけを書く書き出し | 他レイヤーが定義したものを非破壊で上書きするため | 02 |
| `class` | 定義するが、ステージのツリーには現れない雛形 | Inherits の継承元として使うため | 02 |
| 匿名レイヤー | ファイルを持たないレイヤー。identifier が `anon:` で始まる | 一時的な意見を、ファイルに残さず保持するため | 02 |
| 合成アーク | レイヤー／プリムどうしを束ねる有向のつながり1本 | 内容の持ち込み方を複数用意し、用途で使い分けるため | 04 |
| Sublayers | レイヤーに取り付けるアーク。パスを変えない | 同じシーンへの記述を複数ファイルに分担するため | 03 |
| Inherits | プリムに取り付けるアーク。雛形の意見を継承させる | 複数プリムの共通設定を1箇所で一括変更するため | 04 |
| VariantSets | プリムに取り付けるアーク。選択肢から1つを選ぶ | 1ファイルに複数の構成案を持たせ、実行時に切り替えるため | 04 |
| References | プリムに取り付けるアーク。パスを付け替えて配置する | 別ファイルの部品を、任意の場所に何度でも配置するため | 04 |
| Payloads | Reference と同じだが、明示的にロードするまで構成されない | 巨大なシーンを軽く開き、必要な部分だけ読み込むため | 04 |
| Specializes | プリムに取り付けるアーク。特殊化元は常に最も弱い | 土台の設定を使いつつ、個別の上書きを必ず守るため | 04 |
| レイヤースタック | 起点レイヤーから `subLayers` を再帰展開した強さ順の並び | 複数ファイルを1つの合成単位として扱うため | 03 |
| Root Layer | ステージの入口になる1枚のレイヤー | どのファイルからレイヤースタックの展開を始めるかを決めるため | 03 |
| ルートレイヤースタック | Root Layer を起点とするレイヤースタック | Edit Target に選べる範囲を定めるため | 03 |
| LIVRPS | 合成アークの強さ順序（Local / Inherits / VariantSets / References / Payloads / Specializes） | 意見が競合したときの勝敗を一意に決めるため | 05 |
| Local | LIVRPS の L。レイヤースタック全体を指す | SubLayer の意見が Reference の意見より強い理由 | 05 |
| PrimIndex | あるプリムを構成するために辿ったアークの木 | 合成結果がどう作られたかを追跡・デバッグするため | 05 |
| `defaultPrim` | レイヤーメタデータ欄の項目。参照されたときの入口プリム名 | プリムパスを省略した Reference / Payload を成立させるため | 04 |
| Edit Target | いまの編集の書き込み先レイヤー | 複数レイヤーのどれに書くかを明示的に制御するため | 06 |
| Authoring Layer | Edit Target の、Omniverse / Isaac Sim GUI での呼称 | GUI 上で書き込み先を切り替えるため | 06 |
| Session Layer | ステージを開くと自動生成される、最強かつ匿名のレイヤー | ファイルを汚さずに一時的な意見を足すため | 06 |
| Mute | レイヤーを一時的に合成から外すこと。セッション状態 | レイヤーを削除せずに、あり／なしを比較するため | 07 |
| `active` | プリムのメタデータ。`false` にすると子孫ごとツリーから外れる | プリムを削除せずに、一時的に無効化するため | 07 |
| フラット化（flatten） | 合成アークを解決し、結果を1枚のレイヤーに焼き込む操作 | 参照の境界を消し、構造を自由に編集できるようにするため | 08 |

## 2. Python API 対応表

### 2.1 レイヤーを扱う（`pxr.Sdf`）

| API | 何のためにあるか |
|---|---|
| `Sdf.Layer.FindOrOpen(path)` | 既存のレイヤーを開く。同じパスなら常に同じオブジェクトが返る |
| `Sdf.Layer.CreateAnonymous(tag)` | ファイルを持たない匿名レイヤーを作る |
| `layer.identifier` | レイヤーを一意に識別する文字列（通常はファイルパス） |
| `layer.realPath` | ディスク上の実際のパス。匿名レイヤーでは空文字列 |
| `layer.defaultPrim` | `defaultPrim` の読み書き |
| `layer.subLayerPaths` | `subLayers` のリスト。挿入・追加・削除で強さ順を変えられる |
| `layer.pseudoRoot` | レイヤーメタデータ欄を表すオブジェクト |
| `layer.pseudoRoot.ListInfoKeys()` | そのレイヤーに実際に書かれているメタデータ項目を全件返す |
| `layer.dirty` | 未保存の変更があるか |
| `layer.Save()` | ファイルへ書き出す |
| `layer.ExportToString()` | 中身をテキスト形式の文字列として得る |

### 2.2 ステージと合成を扱う（`pxr.Usd`）

| API | 何のためにあるか |
|---|---|
| `Usd.Stage.Open(path)` | Root Layer を指定してステージを開く |
| `Usd.Stage.Open(path, Usd.Stage.LoadNone)` | Payload を読み込まずに開く |
| `stage.GetRootLayer()` | Root Layer を取得する |
| `stage.GetSessionLayer()` | Session Layer を取得する |
| `stage.GetLayerStack()` | ルートレイヤースタックを強い順に列挙する |
| `stage.GetEditTarget()` | いまの書き込み先を取得する |
| `Usd.EditContext(stage, layer)` | `with` ブロックの中だけ書き込み先を変える |
| `stage.Traverse()` | アクティブなプリムを列挙する |
| `stage.TraverseAll()` | 非アクティブなプリムも含めて列挙する |
| `stage.MuteLayer(id)` / `stage.UnmuteLayer(id)` | レイヤーのミュートを切り替える |
| `stage.GetMutedLayers()` | ミュート中のレイヤーを列挙する |
| `stage.FindLoadable()` | Payload としてロード可能なプリムを列挙する |
| `stage.GetLoadSet()` | 実際にロード済みのプリムを列挙する |
| `stage.Flatten()` | 合成結果を1枚のレイヤーに焼き込む |

### 2.3 プリムと属性を調べる

| API | 何のためにあるか |
|---|---|
| `prim.GetPrimStack()` | そのプリムを構成している PrimSpec を、出所のレイヤーごとに列挙する |
| `prim.GetPrimIndex().DumpToString()` | 構成に使われたアークの木をテキストで書き出す |
| `prim.HasAuthoredReferences()` | Reference が張られているかを判定する |
| `prim.IsActive()` / `prim.SetActive(bool)` | `active` の読み書き |
| `prim.GetReferences().AddReference(path)` | Reference を追加する |
| `prim.GetVariantSets()` | VariantSet の一覧と選択状態を扱う |
| `attr.Get()` | 合成結果の値（＝勝った意見の値）を取る |
| `attr.Set(value)` | 値を書き込む。失敗しても例外を投げず `False` を返す |
| `attr.GetPropertyStack(Usd.TimeCode.Default())` | その属性についての意見を強い順に列挙する |

### 2.4 Isaac Sim / Omniverse Kit のコマンド（`omni.kit.usd.layers`）

| コマンドクラス | 何のためにあるか |
|---|---|
| `CreateSublayerCommand` | SubLayer を新規作成または既存ファイルを挿入する |
| `RemoveSublayerCommand` | SubLayer を親レイヤーから外す |
| `MoveSublayerCommand` | SubLayer の位置を移動し、強さ順を変える |
| `ReplaceSublayerCommand` | SubLayer を別ファイルに差し替える |
| `MergeLayersCommand` | 2枚のレイヤーを統合する |
| `FlattenLayersCommand` | レイヤースタックを平坦化する |
| `StitchPrimSpecsToLayer` | 特定のプリムだけを平坦化して1枚に集める |
| `SetEditTargetCommand` | レイヤーを Edit Target にする |
| `SetLayerMutenessCommand` | レイヤーのミュート状態を設定する |
| `LockLayerCommand` | レイヤー単位で書き込みを禁止する |
| `LockSpecsCommand` / `UnlockSpecsCommand` | プリム単位で編集を禁止・解除する |
| `LinkSpecsCommand` / `UnlinkSpecsCommand` | プリムを特定レイヤーに紐付ける・解除する |
| `AutoAuthoring` | Edit Target を自動で振り分ける（実験的機能） |
| `LiveSession` | Session Layer 経由のリアルタイム同期を扱う |

## 3. 迷ったときの判断表

| 状況 | 使うもの |
|---|---|
| 別のものを置きたい（部品の配置） | References |
| 同じものへの記述を分けたい（担当の分割） | Sublayers |
| 重いアセットを含むシーンを軽く開きたい | Payloads |
| 複数プリムの共通設定を1箇所で変えたい | Inherits |
| 1ファイルに複数案を持たせて切り替えたい | VariantSets |
| ファイルを汚さず一時的な意見を足したい | Session Layer を Edit Target にする |
| レイヤーのあり／なしを比較したい | Mute |
| プリムを削除せず無効化したい | `active = false` |
| 参照の境界を消して構造を編集したい | フラット化 |

## 4. 症状から原因を引く表

| 症状 | 疑うもの | 確認方法 |
|---|---|---|
| Reference したのに何も出てこない | 参照先の `defaultPrim` が未設定 | `layer.defaultPrim` が空文字列か |
| ファイルに書いてあるのにステージに出ない | 07 の5系統 | 07 の診断コード |
| 書き込んだのに見た目が変わらない | 自分のレイヤーが負けている | `attr.GetPropertyStack()` の並び |
| `Set()` が `False` を返す | 書き込み自体が失敗している | 戻り値と Edit Target を確認 |
| プリムを移動できない | Reference の名前空間カプセル化 | `prim.GetPrimStack()` に外部ファイルが出るか |
| 昨日は見えたのに今日は見えない | Mute か Payload 未ロード（セッション状態） | `GetMutedLayers()` と `GetLoadSet()` |
| 保存したのに他の人に反映されない | Edit Target が Session Layer になっている | `stage.GetEditTarget()` |
